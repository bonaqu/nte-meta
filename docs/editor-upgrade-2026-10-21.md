# NTE Meta: редактор, медиа и источники — 21 октября 2026

Связано с #37. Изменения продолжают аудит #34.

- Тир-лист обновляется из успешного ответа записи и закрывает редактор. Проверен реальный сценарий с 24 позициями: добавить Аканэ в S, сохранить, перезагрузить и повторно открыть. Редкость персонажа и боевой тир остаются разными данными.
- После входа загружаются редакторские коллекции: скрытые источники больше не приводят к неполному списку при сохранении порядка секций.
- Добавлены визуальные дуги, картриджи, статы, приоритет навыков и пошаговая ротация. Есть порядок рекомендаций, характеристики, изображения, ручная правка и предпросмотр. Отряды и командные ротации остаются в существующем отдельном блоке.
- В шести опубликованных гайдах предусмотрено 30 визуальных секций. Миграция сравнивает известный исходный текст и сохраняет авторские изменения. Старые объединённые сборки архивируются для редактора. Ссылки и служебные оговорки скрыты от читателя.
- Загрузка PNG/JPEG/WebP с компьютера подключена к изображениям и визуальному редактору текста. Файл сжимается в браузере; API проверяет формат, размер и права. Публичный URL работает сразу, содержимое хранится отдельно от Markdown. GitHub Actions архивирует только публичные изображения в `public/uploads/<контекст>/<hash>.<ext>`; токен GitHub не передаётся клиенту. Период запуска — каждые 15 минут, фактический запуск зависит от очереди GitHub.
- Подключены Nanoka с определением текущей версии данных и изображения Kaiden. Экипировка ищется отдельно в двух базах, с изображением, эффектами и характеристиками; уровень характеристики указан явно. Проверены 42 URL изображений из подготовленных визуальных секций: HTTP 200.
- Исправлен разбор названий навыков: предложения из описания механики отбрасываются. Миграция удаляет только известную ошибочно импортированную строку Реморы.
- Реестр расширен до 32 источников EN/RU/JP/CN. Мультигровые каналы фильтруются по NTE. Можно подключить свой публичный Telegram, Reddit или RSS/Atom, указать язык, направление и выключить поиск в управлении источниками.
- Новости и слухи фильтруются отдельно. Официальное объявление в канале сливов не должно автоматически попадать в слухи. Это редакционная классификация: результат поиска остаётся кандидатом, публикация требует решения администратора.
- Перевод на русский показывается как редактируемое предложение Google Translate с терминологией NTE и русскими именами персонажей. Оригинал сохраняется; принятие перевода не публикует материал. Ограничения внешнего переводчика и источников отображаются в интерфейсе.
- Для SQL закреплён LF: строковые условия миграций одинаковы в Windows и Linux CI.

Проверки: lint, TypeScript; общий прогон 80 тестов; дополнительные 11 проверок редактора/импорта; живой поиск (100 кандидатов, поиск официальных анонсов, Nanoka и экипировка); архив медиа (байты, повторный экспорт, пагинация и запрет выхода из папки). На копии производственного SQL-экспорта: 24 персонажа, 6 гайдов, 30 визуальных секций, 0 ошибок FK; пользовательские таблицы сохранены. Миграции не изменяют тир-лист; ручной S Аканэ дополнительно покрыт тестом.
