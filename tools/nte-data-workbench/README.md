# NTE Meta — локальная выгрузка

Запуск на этом компьютере: дважды нажмите **Start.cmd**. Программа использует общий Python из `D:\CODEX\Programs\Python312`, UEExtractor, .NET и FFmpeg; копировать их в папку игры не нужно.

## После обновления игры

1. Закройте игру и дождитесь окончания обновления в лаунчере.
2. Откройте программу. Проверьте папку игры, UEExtractor, `.usmap` и путь к файлу ключа архивов. Текущие рабочие пути уже подставлены; ключ не показывается в окне и не сохраняется в Git.
3. Нажмите **1 · Извлечь обновление**. Новая выгрузка появится в отдельной папке с датой. Поле «Рабочая выгрузка (для шагов 2–3)» переключится на неё автоматически.
4. При необходимости нажмите **2 · Обновить дополнение**. Это отдельная сетевая операция: Nanoka дополняет материалы и дуги, Kaiden — награды симпатии, Neverness.app — подарки. Происхождение записей сохраняется; данные не выдаются за извлечённые из игры.
5. Нажмите **3 · Подготовить снимок игры**. Будут созданы снимок справочника, WebP, Opus и проверенная SQLite-копия. Обработка аудио при первом запуске занимает больше времени; готовые файлы используются повторно.
6. Нажмите **4 · Каталог игрока / Excel / MP3** и выберите родительскую папку. Программа создаст новый каталог `NTE-дата-время`, не перезаписывая прошлый экспорт. Нажмите **Открыть каталог игрока**: откроется `Для игрока/Начать здесь.html`. Для технической работы также остаются `Открыть отчёт.html` и полный Excel.

Извлечение читает архивы через ссылки во внешней рабочей папке. Оно не меняет установку игры. Не запускайте извлечение одновременно с обновлением: ссылки относятся к текущим архивам, а не к их резервной копии.

## Каталог для обычного игрока

Начальная страница — **`Для игрока/Начать здесь.html`**. Для просмотра интернет не нужен. Все имена и описания берутся из подтверждённых связей клиента; отсутствующие подписи не придумываются.

- **Персонажи:** отдельное досье и восемь страниц: биография с паспортом и актёрами, начальные характеристики, навыки по типам с таблицами уровней, шесть пробуждений и резонансы 3/6, возвышения с материалами и опытом, уровни симпатии и любимые подарки, гардероб, озвучка по языкам.
- **Экипировка:** дуги, картриджи и консоли. Доступные эффекты и характеристики, значения дуг по уровням, материалы возвышения.
- **Предметы:** категории по назначению, включая опыт персонажа/дуги/модулей, материалы возвышения, еду, подарки, валюты, мебель, транспорт, задания и коллекции.
- **Медиатека:** все извлечённые изображения в PNG, группы по назначению, по 100 изображений на странице. Если название или владелец не подтверждены, остаются изображение и исходный путь в раскрываемом блоке.
- **Реплики:** MP3 с названием игровой ситуации, папки персонажей и языков; текст реплики рядом с проигрывателем. Дополнительные и старые игровые ID вынесены в «Архив озвучки». Неизвестная ситуация явно подписана как неизвестная.
- **Понятный Excel:** `Для игрока/NTE — для игрока.xlsx`, русские заголовки, отдельные листы для навыков, параметров, пробуждений, возвышений, подарков, гардероба и реплик. Фильтры и ссылки на досье/MP3.

**WEM — рабочий формат игры.** Папка вида `дата/export/audio/English` содержит исходные `.wem`, а не WAV/MP3 для обычного проигрывателя. Чтобы получить готовую озвучку, выполните шаг 3, затем 4 с включёнными медиа. Кнопка **Открыть рабочую папку** открывает исходники; **Открыть каталог игрока** открывает готовый результат. Подсказки доступны при наведении на каждое поле и кнопку, а также при переходе клавишей Tab.

Первое создание досье занимает больше времени: используется тот же обработчик таблиц, что и на сайте. Результат кешируется по хешу снимка и кода обработчика; после обновления данных кеш строится заново. Экспорт PNG/MP3 требует больше места, чем сжатые WebP/Opus сайта. Переключатель медиа позволяет получить только текст и таблицы.

## Полные технические данные



- **Excel:** листы по категориям, ID, владелец, таблица, RU/EN/JA/ZH, ссылки на медиа и исходные поля. Используйте фильтры Excel; длинные поля указывают на полную строку JSONL.
- **Категории:** CSV с UTF-8 BOM и полные JSONL. Строки не обрезаются в единственной копии данных.
- **Персонажи:** папка `игровой ID — имя`, отдельные разделы и собственная папка медиа. Общие записи без доказанной связи с персонажем остаются в общих категориях.
- **Медиа:** изображения и реплики. В папках персонажей создаются жёсткие ссылки на центральные файлы, где файловая система это поддерживает; иначе — копии.
- **manifest.json:** счётчики, хеш снимка, ошибки и список пустых таблиц. `namespace`, `gameId`, `details.references` и `assets.path` помогают проследить исходную связь.

Старые ID и действующие персонажи сохраняются отдельно. Категория — подсказка; точное назначение задают исходная таблица и связи. Внешние дополнения отмечены в `details.reference`.

## Публикация на сайте

Подготовка обновляет файлы в этом репозитории: `scripts/content/game-data` и `public/game-assets`, `public/game-audio`. Для публикации создайте Issue и PR с изменёнными файлами, дождитесь проверок и объедините PR. GitHub Pages публикует интерфейс и медиа. Затем запустите **Actions → Deploy Cloudflare Worker → Run workflow** на основной ветке: workflow применит миграции и импортирует снимок в D1. Ручные правки справочника хранятся отдельно от снимка и сохраняются при повторном импорте.

Сам экспорт Excel ничего не публикует. Он содержит полный снимок, подготовленный последней успешной операцией 3, а не произвольные файлы из поля «Существующая выгрузка».

## Ограничения, которые нужно видеть

Пустая таблица или отсутствующий файл не заменяются вымышленными данными. В текущей установке есть банки английской и японской озвучки; китайский и корейский пакеты не установлены. После установки соответствующего пакета штатным лаунчером повторите извлечение. Шесть английских событий указывают на нулевой ID медиа и остаются без аудио.

После патча формат архивов может потребовать обновлённый `.usmap` или ключ. Если чтение завершилось ошибкой, сохраните журнал и предыдущий рабочий снимок; программа не подбирает ключи и не изменяет защиту игры. Журналы UEExtractor могут содержать технические данные ключа — не публикуйте их.
